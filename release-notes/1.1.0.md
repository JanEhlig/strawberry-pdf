Editing existing text

- In the Text tool, point at a line and click it to edit it. Selecting a line and choosing Edit text works as before.
- Edited text keeps the original font, size, color, letter spacing and position.
- Characters that are missing from the font embedded in the PDF are taken from the same font on your computer, or from a close match if it is not installed.
- Polish, Czech, Turkish, Greek, Cyrillic and other special characters are written correctly.
- The text size can be adjusted while editing.
- Saving right after an edit always includes the edit.
